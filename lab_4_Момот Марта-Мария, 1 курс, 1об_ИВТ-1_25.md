Задание 1.4. Смешанное произведение трёх векторов в 3D
• Цель: вычислять смешанное произведение через разбиение задачи на небольшие понятные функции.
• Что подать на вход: три вектора длины 3 в декартовых координатах (x, y, z).
• Обязательные интерфейсы функций: void cross3(const double a[3], const double b[3], double out[3]); double dot3(const double a[3], const double b[3]); double triple3(const double a[3], const double b[3], const double c[3]);
• Что считается корректным результатом:
1. реализована функция векторного произведения двух 3D-векторов (результат — вектор длины 3);
2. реализована функция скалярного произведения двух 3D-векторов (результат — число);
3. реализована функция смешанного произведения [a,b, c] = a · (b × c); 4. функция смешанного произведения использует две предыдущие функции, а не дублирует формулы вручную.
• Пошаговый алгоритм:
4. сначала вычислите tmp = b x c с помощью cross3;
5. затем вычислите число a . tmp с помощью dot3;
6. это число и есть значение triple3(a, b, c). • Справочная формула для векторного произведения: b × c = (bycz − bzcy, bzcx − bxcz, bxcy − bycx).
• Пояснение для интерпретации результата: смешанное произведение — это ориентированный объём параллелепипеда, построенного на векторах a,b, c. Если значение равно нулю, то векторы компланарны.
• Мини-пример: a=(1,0,0), b=(0,1,0), c=(0,0,1) → [a,b,c]=1.

void vp(const double s1[3], const double s2[3], double itg[3]) {
    itg[0] = s1[1] * s2[2] - s1[2] * s2[1];
    itg[1] = s1[2] * s2[0] - s1[0] * s2[2];

double sk(const double s1[3], const double s2[3]) {

}

            printf("Ошибка: переполнение диапазона\n");

            while (*p && isspace((unsigned char)*p)) p++;
            if (*p != '\0') printf("Лишние символы: %s", p);
        }
    }
    <span style="color:green">return 0</span>;
}
