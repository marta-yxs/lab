Задача 1 - Сложение через указатели
Постановка задачи
Цель: получить значение переменных через указатели. Вход: два целых числа a, b. Выход: сумма чисел. Требование: складывать значения через указатели int *pa, int *pb. Пример: Ввод: 8 9 Вывод: 17

Список идентификаторов

| -------------------|-------------------------|------------------------------------|
|Имя переменной|       Тип данных          |     Описание                               |
| -------------------|-------------------------|------------------------------------|
|      arr            |      int*                        |Указатель на массив из 2 чисел|
| -------------------|-------------------------|------------------------------------|
|-------sum-------|-------int-------|-------Сумма---------------------------|

Код программы

<font color="yellow">#include</font> <font color="green"><stdio.h></font>

<font color="yellow">#include</font> <font color="green"><stdlib.h></font>

<font color="red">int</font> main(<font color="red">void</font>) {

    int* arr;
    int sum;
    arr = (int*)malloc(2 * sizeof(int));

    scanf("%d", &arr[0]);

    scanf("%d", &arr[1]);
    sum = arr[0] + arr[1];

    printf("%d", sum);

    free(arr);
    <font color="green">return 0</font>;
}

Задача 2 - Обмен двух чисел
Цель: изменить данные по адресу (swap). Вход: два целых числа a, b. Выход: сначала исходные, затем обменённые значения. Требование: обмен выполнять через указатели. Пример: Ввод: 3 7 Вывод: 3 7 и затем 7 3

Список идентификаторов

| -------------------|-------------------------|------------------------------------|

|Имя переменной|       Тип данных          |     Описание                               |

| -------------------|-------------------------|------------------------------------|

|      arr                   |      int*                        |Указатель на массив из 2 чисел|

-------------------|-------------------------|------------------------------------|

|_____i___________|__________int__________|Переменная для обмена_____________|

Код программы

<font color="yellow">#include</font> <font color="green"><stdio.h></font>

<font color="yellow">#include</font> <font color="green"><stdlib.h></font>

<font color="red">int</font> main(<font color="red">void</font>) {

    int* arr;
    int i;
    arr = (int*)malloc(2 * sizeof(int));
    scanf("%d", &arr[0]);
    scanf("%d", &arr[1]);
    printf("%d %d\n", arr[0], arr[1]);

    i = arr[0];
    arr[0] = arr[1];
    arr[1] = i;

    printf("%d %d", arr[0], arr[1]);

    free(arr);
    <font color="green">return 0</font>;
}

Задача 3 - Максимум через указатели
Цель: условие с обращением по указателю. Вход: два целых числа. Выход: максимальное из них. Требование: сравнивать значения через указатели. Пример: Ввод: 11 4 Вывод: 11

Список идентификаторов

| -------------------|-------------------------|------------------------------------|
|Имя переменной|       Тип данных          |     Описание                             |

| -------------------|-------------------------|------------------------------------|

|      a                     |      int*                        |Указатель на 1 число           |

|-------------------------|-------------------------|-------------------------|

|_______b___________|---------int*---------|Указатель на 2 число__________|

|___max____________|__________int__________|Максимальное значение___________|

Код программы

<font color="yellow">#include</font> <font color="green"><stdio.h></font>

<font color="yellow">#include</font> <font color="green"><stdlib.h></font>


<font color="red">int</font> main(<font color="red">void</font>) {

    int *a, *b;
    int max;

    a = (int*)malloc(sizeof(int));
    b = (int*)malloc(sizeof(int));

    scanf("%d %d", a, b);

    if(*a > *b) {
        max = *a;
    } else {
        max = *b;
    }

    printf("%d\n", max);

    free(a);
    free(b);
    <font color="green">return 0</font>;
}

Задача 4 - Динамический массив и сумма
Цель: выделить память под массив и пройти его указателем. 
Вход: число n, затем n целых чисел. 
Выход: сумма всех элементов. 
Ограничения: 1 <= n <= 1000. Требование: обход элементов через арифметику указателей. Пример: Ввод: 4 и 2 3 4 5 Вывод: 14

Список идентификаторов

| -------------------|-------------------------|------------------------------------|

|Имя переменной|       Тип данных          |     Описание                        |
| -------------------|-------------------------|------------------------------------|

|      n                  |      int                    |Число элементов             |
| -------------------|-------------------------|------------------------------------|

|___arr___________|---------int*---------|Указатель на начало массива________|

|_____k___________|---------int*---------|Указатель обхода массива___________|

|_____sum________|__________int__________|Суммарное значение_______________|

Код программы

<font color="yellow">#include</font> <font color="green"><stdio.h></font>

<font color="yellow">#include</font> <font color="green"><stdlib.h></font>

<font color="red">int</font> main(<font color="red">void</font>) {

    int n;
    int* arr;
    int* k;
    int sum = 0;
    scanf("%d", &n);

    arr = (int*)malloc(n * sizeof(int));
    for (k = arr; k < arr + n; k++) {
        scanf("%d", k);
    }

    for (k = arr; k < arr + n; k++) {
        sum = sum + *k;
    }

    printf("%d\n", sum);

    free(arr);
    <font color="green">return 0</font>;
}

Задача 5 - Обратный вывод динамического массива
Цель: декремент указателя. 
Вход: число n, затем n целых чисел. 
Выход: элементы в обратном порядке. 
Ограничения: 1 <= n <= 1000. 
Требование: использовать указатель и операцию --. 
Пример: Ввод: 3 и 10 20 30 
Вывод: 30 20 10

Список идентификаторов

| -------------------|-------------------------|------------------------------------|
|Имя переменной|       Тип данных          |     Описание               |
| -------------------|-------------------------|------------------------------------|
|      n                   |      int                     |Число элементов            |

|-----------------------|-------------------------|-------------------------|

|------arr--------|---------int*---------|Указатель на начало массива__|

|------k-----|---------int*---------|Указатель обхода массива______|

Код программы

<font color="yellow">#include</font> <font color="green"><stdio.h></font>

<font color="yellow">#include</font> <font color="green"><stdlib.h></font>

<font color="red">int</font> main(<font color="red">void</font>) {
    int n;
    int* arr;
    int* k;

    scanf("%d", &n);

    arr = (int*)malloc(n * sizeof(int));
    for (k = arr; k < arr + n; k++) {
        scanf("%d", k);
    }

    for (k = arr + n - 1; k >= arr; k--) {
        printf("%d ", *k);
    }
    printf("\n");

    free(arr);
    <font color="green">return 0</font>;
}

Задача 6 - Побайтовый вывод int
Цель: понять, как данные хранятся в памяти. 
Дано: int a = 1234567890; 
Выход: значения байтов переменной (в десятичном виде). 
Требование: использовать указатель unsigned char *.

Список идентификаторов

| -------------------|-------------------------|------------------------------------|
|Имя переменной|       Тип данных          |     Описание              |

| -------------------|-------------------------|------------------------------------|

|      n               |      int                   |Число элементов           |
| -------------------|-------------------------|------------------------------------|

|-------k---------|unsigned char*----------|Указатель на байт------------|

|---------i------|------------int*|Счетчик байт------------|

Код программы

<font color="yellow">#include</font> <font color="green"><stdio.h></font>

<font color="yellow">#include</font> <font color="green"><stdlib.h></font>

<font color="red">int</font> main(<font color="red">void</font>) {
    int a = 1234567890;
    unsigned char* k;
    int i;
    k = (unsigned char*)malloc(sizeof(int));

    k = (unsigned char*)&a;

    printf("%d\n", a);

    for (i = 0; i < sizeof(int); i++) {
        printf("%d\n", *(k + i));
    }

    free(k);
    <font color="green">return 0</font>;
}

Задача 7 - Динамическая матрица 2x3
Цель: базовая работа с двумерным динамическим массивом. 
Вход: 6 целых чисел для матрицы 2 x 3. 
Выход: та же матрица построчно. 
Требование: выделить память как массив указателей на строки и корректно освободить. Пример: Ввод: 1 2 3 4 5 6 
Вывод: 
1 2 3 
4 5 6

Список идентификаторов

| -------------------|-------------------------|------------------------------------|

|Имя переменной|       Тип данных          |     Описание                   |
| -------------------|-------------------------|------------------------------------|

|      n           |      int**                     |Матрица                  |
| -------------------|-------------------------|------------------------------------|

|------------i----------|int-------------------------|Счетчик строк------------|

|------------j----------|-------int*------------|Счетчик столбцов---------------------|

Код программы

<font color="yellow">#include</font> <font color="green"><stdio.h></font>

<font color="yellow">#include</font> <font color="green"><stdlib.h></font>

<font color="red">int</font> main(<font color="red">void</font>) {
    int** n;
    int i, j;
    n = (int**)malloc(2*sizeof(int*));
    for (i = 0; i < 2; i++) {
        n[i]=(int*)malloc(3*sizeof(int));
    }
    for (i=0; i<2; i++) {
        for (j=0; j < 3; j++) {
            scanf("%d", &n[i][j]);
        }
    }
    for (i = 0; i < 2; i++) {
        for (j=0; j < 3; j++) {
            printf("%d ", n[i][j]);
        }
        printf("\n");
    }
    for (i=0; i<2; i++) {
        free(n[i]);
    }
    free(n);
    <font color="green">return 0</font>;
}
